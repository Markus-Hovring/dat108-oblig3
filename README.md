# Oblig 3 - Terrengløp

Oblig 3 i DAT108. En nettside der man kan legge til deltagere i et terrengløp.

## Hvordan kjøre

Åpne `konk/index.html` i nettleseren.

## Hva den gjør

- Legge til deltagere med startnummer og navn
- Sjekker at startnummer og navn er gyldige
- Skrive inn starttid og sluttid, og så regnes løpstiden ut
- Filtrere deltagerlisten
